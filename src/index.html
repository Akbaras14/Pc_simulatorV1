Cara bermain

Klik “Lanjutkan step” untuk memasukkan komponen satu per satu. Setelah PC selesai dirakit, letakkan monitor, mouse, dan keyboard di siluet hijau di atas meja. Setelah monitor, mouse, dan keyboard terpasang, colokkan flashdrive ke PC sebelum menyalakannya. Kamera kemudian mendekat ke monitor. Nyalakan PC, tekan F2/DEL/ESC saat boot, buka Boot, pilih USB sebagai First Boot, lalu F10 dan Yes. Setelah loading 100%, animasi Windows dan Bengkel Coding tampil sebelum desktop. Klik aplikasi di monitor atau sidebar untuk membukanya. Gunakan Inspeksi untuk melihat seluruh model 3D.
